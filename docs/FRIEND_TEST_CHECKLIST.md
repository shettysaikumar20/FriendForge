# Friend Testing ? 10?15 minutes

Use non-sensitive real study notes. The sample download is demo content, not real friend data. Ask the tester to think aloud; do not coach them through every control.

1. Open FriendForge. Can you tell what to do first? (1 minute)
2. Upload a PDF or TXT file and wait for Indexed and ready. (2 minutes)
3. Ask a question answered by the notes; check the source filename. Also ask one question the notes cannot answer. (2 minutes)
4. Choose Explain and ask about one difficult concept. (1 minute)
5. Choose Quiz Me, enter a specific topic, and complete all five questions. Check explanations against your notes. (3 minutes)
6. Look at Study Memory. Tell FriendForge explicitly which topic needs practice if none is saved. (1 minute)
7. Choose Revise. Does the selected topic match your needs? (1 minute)
8. Start New Study Session. Chat and attached-note context reset; memory remains. Ask which topic you struggle with. (1 minute)
9. Check Clear study memory, then Cancel. Only actually delete if the tester wants to. New Session does not delete remote documents or chat history.
10. Collect feedback. Record errors, long waits, misleading answers and requested changes. (2 minutes)

Ask:
- What was most useful?
- What was confusing?
- Would you actually use this before an exam?
- What is one thing you would change?
